# M23 P8.1 — Adjacent-stage matrix

Every boundary of the journey (§4) attacked ten ways. "Refused" names the
server's answer; "check" names the assertion in
`m23RecruitmentJourneyHardeningE2E` (group letters) or an earlier suite that
already proves the cell. The ONE validator (`canTransitionRecruitmentCase`)
and each domain's own gate answer every cell; no client decides any of it.

Legend for the ten attacks: **F** valid forward · **S** stale source state ·
**D** duplicate request · **C** concurrent conflicting request · **A**
authority loss before the mutation · **B** block inserted before the
mutation · **W** wrong-case resource · **P** foreign-player resource ·
**R** restart between steps · **M** malformed evidence.
