# M23 P8.1 — Defect register

Every finding of the hostile whole-journey review (§2) with the fields §87
requires. Severity: Critical (authoritative truth writable by the wrong
party), High (authorization, privacy, data integrity, a dead end that loses
a live recruitment), Medium (correctness a user or an auditor would notice;
an unmetered alias), Low (honesty, wording, replay semantics).
